
AI COPILOT SYSTEM CONTEXT
========================
SISTEM AGENDA, ABSENSI, NILAI, IZIN & KEAMANAN SEKOLAH
Framework: Laravel
Tujuan: Menjadi konteks permanen AI Copilot saat coding

=====================================================
1. ROLE & USER SISTEM
=====================================================
- Admin
- Kepala Sekolah
- Guru Kelas
- Wali Kelas
- Guru Mapel
- Guru BK
- Guru Piket
- Siswa (KM)
- Petugas Keamanan

=====================================================
2. MASTER TAHUN AJARAN & SEMESTER
=====================================================
tahun_ajaran
- id (PK)
- nama_tahun
- is_active

semester
- id (PK)
- tahun_ajaran_id (FK)
- nama_semester (Ganjil/Genap)
- is_active

ATURAN:
- Hanya 1 tahun ajaran aktif
- Hanya 1 semester aktif
- Semua data wajib terikat tahun & semester

=====================================================

guru

- kelas_id
- status_aktif

10. EXPORT - IMPORT DATA
=====================================================

=====================================================
11. PRINT & LAPORAN
=====================================================
- Print agenda kelas (PDF)
- Print agenda guru (PDF)
- Print agenda piket (PDF)
- Print rekap absensi
- Print rekap izin siswa
- Print nilai harian

=====================================================
12. FLOW UTAMA SISTEM
=====================================================
1. Admin set tahun ajaran & semester aktif
2. Admin input jam belajar
3. Guru input agenda sesuai jam belajar
4. Guru mengisi absensi kelas
5. Sistem generate absensi siswa
6. Siswa ajukan izin -> guru piket
7. Petugas keamanan verifikasi keluar
8. Guru input nilai harian
9. Wali kelas & BK monitoring
10. Kepala sekolah melihat dashboard & laporan

=====================================================
CATATAN UNTUK AI COPILOT
=====================================================
- Semua query WAJIB filter tahun_ajaran_id & semester_id
- Gunakan RBAC (Policy & Middleware)
- Jangan izinkan data di luar jam belajar
- Semua laporan wajib bisa PDF & Excel
